## 每次 Release 的执行顺序

1. 在两种桌面平台分别用真实引擎完成“棋谱 → 归档 → 报告 → 训练 → 导出”闭环。
2. 断网执行本地棋谱操作，恢复网络后验证同步 outbox；没有测试账号时保持“条件验证”。
3. macOS 单独检查屏幕录制、辅助功能拒绝和授权后的连线停启；Windows 单独以 Chrome 和 Edge 在 100%/125% 缩放下检查窗口选择、局面同步、窗口移动后的重标定与确认走子。没有真机记录时保持“实验”。
4. 将结果、应用版本、引擎版本和已知限制同步写入发布说明与 `docs/DESKTOP_FUNCTION_AUDIT.md`。

任何一项没有真实验收时不得在发布说明标注“已支持”；应保留其条件或实验状态和用户可见的降级路径。
