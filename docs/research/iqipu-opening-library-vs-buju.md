# 爱棋谱：综合开局库与布局页的区别

调研日期：2026-09-08。结论基于爱棋谱公开的一方页面和目录 API；页面中的局数、文件大小和更新时间均为当日快照。

## 结论

两者不是同一种“开局库”。`/tools/xqb` 是供象棋软件按当前局面查着的**开局文件分发/管理入口**；`/buju` 是按开局分类组织的**棋谱内容浏览与复盘入口**。它们可共享“局面/着法前缀”底层模型，但桌面端应是两个独立工作面，不能把导入的综合 XQB 误作布局百科。

| 维度 | 综合开局库 `/tools/xqb` | 象棋布局 `/buju` |
| --- | --- | --- |
| 核心对象 | `.xqb` 文件，鲨鱼可直接载入；可转换为兵河 `.obk` | A--E 开局体系及编码布局（如 `A45`、`C06`）下的棋局集合 |
| 数据组织 | 一个“综合”包加多个按布局拆分的文件包 | 分类目录 -> 布局详情 -> 对局、棋手和相近布局 |
| 主要行为 | 检索/选择谱册、查看规模和兼容性、打开百度网盘、复制提取码/地址；另链到在线拆棋 | 搜索与展开分类、进入布局详情、按胜负/年代/赛事/最新热门筛选、打开棋局复盘、收藏/订阅（登录态能力） |
| 用户目标 | 将本地或外部引擎接入某套候选着法库，并在局面上快速查招 | 学习某种布局，筛选和回看该布局下的实战棋谱 |

## 一方证据

- [开局库首页](https://www.iqipu.com/tools/xqb) 明示“鲨鱼直接打开 XQB，转 OBK 即可用于兵河”，并把“网页摆子即查”的在线体验导向 `/chaiqi`；本页自身提供的是网盘领取、复制和按布局选择，而不是棋局浏览器。
- 同页的[综合库详情](https://www.iqipu.com/tools/xqb/all)把“综合开局库”描述为“全部布局合成一本”；这说明“综合”指打包覆盖范围，不是另一个开局分类体系。
- 一方[开局库目录 API](https://www.iqipu.com/web/api/xqb_books.php?action=catalog)提供 `games`、`lines`、`positions`、`size`、`updated_at`、`compat` 与网盘交付字段。调研时 `all` 项为 `kind=all`、`source=pool`，而其它条目为按布局划分的 `kind=layout`。
- [布局总览](https://www.iqipu.com/buju)说明按 A--E 开局体系浏览，并宣称汇集大师对局、支持红胜/黑胜与变着筛选、在线打谱复盘；主页展示热门布局和每类收录局数。
- [A45 起马互进七兵局详情](https://www.iqipu.com/buju/a45)显示布局介绍、对局总量和红/黑胜和统计，以及胜负、年代、赛事、排序筛选、棋局列表、擅长棋手和相近布局。这验证了 `/buju` 的核心是分类棋谱探索，不是下载某个引擎开局文件。

## 桌面端建议

可以做类似设计和功能，但建议保留现有本地优先原则，并拆为两个入口：

1. **本地开局库**：导入/启停/删除外部开局库，展示文件来源、格式、大小、覆盖局面数和更新时间；在当前 FEN 查询合法候选着法及库统计。XQB 是否能完整解析或仅作为外部引擎资源，应以真实样例验收为准。
2. **布局探索**：维护可版本化的布局分类（代码、名称、标准着法前缀/FEN、说明），从本地棋谱库检索匹配对局；提供胜负、年代、赛事、棋手筛选，点击后进入现有非破坏性棋谱复盘。
3. **连接方式**：布局详情可提供“在本地库查此局面”和“用引擎分析此布局”命令；开局库查询结果可反向显示已知布局标签。两边共享局面键和走法前缀，但各自拥有不同的来源、可信度和更新机制。

不建议照搬百度网盘交付或把网页统计硬编码进应用。桌面版本应以本地 SQLite 元数据、用户导入文件和可追溯来源为准；云库查询失败也不得影响本地打谱或引擎分析。
