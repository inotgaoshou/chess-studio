# Mac 本机大师棋谱库

完整大师棋谱列表由本机 MySQL 和 `xiangqi-server` 提供。桌面内置的赵鑫鑫画像、开局识别、飞刀专题和本地 Pikafish 不依赖这项服务。

## 首次配置

1. 启动已有的 MySQL 服务。Homebrew 安装可使用 `brew services start mysql`；官方安装包可在系统设置或 MySQL 的启动脚本中启动。
2. 确认旧项目的 `xiangqi` 数据库可访问。不要重新导入已经存在的 `master_games`、`master_game_moves` 和 `master_players`。
3. 复制 `.env.example` 为 `.env`，填写实际的本机 MySQL 账号、密码和新的随机 `JWT_SECRET`。服务仅绑定 `127.0.0.1:8080`。
4. 在项目根目录执行 `scripts/dev-server.sh start`。启动时会创建缺失的表，并为已有棋谱幂等补充中炮、挺三兵、中炮三兵标签。
5. 用 `curl http://127.0.0.1:8080/health` 检查服务；用 `scripts/dev-server.sh logs` 查看失败原因，`scripts/dev-server.sh stop` 停止服务。

## 日常学习

1. 打开桌面端的“大师棋谱”，搜索并选择“赵鑫鑫”。
2. 在棋谱筛选中选择执红/执黑、年份或“中炮三兵”。筛选只读取本机公开棋谱库，不上传棋谱。
3. 从赵鑫鑫专题卡进入“中炮三兵实战”，打开一局后选择“分析打分”或在复盘页开始引导拆棋。
4. 点击“进入三兵飞刀课”，依次完成布局目标、实战应对和陷阱防守；推演不会写入原棋谱，保存练习后才会生成本地训练任务。
5. 完成整局本地复盘后，可把问题着加入训练并导出本地 PDF。PDF 不包含数据库地址、账号、令牌或引擎路径。

## 故障边界

当大师谱窗口提示“本机大师谱服务未启动”时，先启动 MySQL，再运行 `scripts/dev-server.sh start`。这不会影响离线专题和本地引擎分析。服务端不监听局域网或公网地址。
