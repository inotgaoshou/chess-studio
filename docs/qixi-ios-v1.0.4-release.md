# 棋析 iOS 1.0.4 发布范围

基线为线上 1.0.3（10018）。本次仅 iOS App Store 更新，版本 1.0.4，构建 10020，生产 API 固定 https://api.qixiapp.cn；审核后手动发布。

## 相对 1.0.3

- 各输入入口防键盘、输入法候选栏与底部按钮遮挡；iPhone 系统“完成”收起键盘，多行回车换行，保留草稿。
- 作业正文与步骤操作区独立布局，分批设置、最后一项、汇总完整可见。
- 作业上一题／下一题、题号网格、预览列表；题号支持收起展开并记住选择。
- 切题保留棋盘与相同棋子图片，准备完毕后统一更新标题、题号和局面；慢网、失败、重试及迟到请求保护。
- 教师试做无须提交，进度只存本机；支持修改本次作业指定题内容、摆棋、答案树、替换、撤回、重发和公共原题纠错。保留学生旧记录并可历史回放，当前成绩仅统计有效题目。
- 教师试做优先显示棋盘，管理入口收进“更多”，试做期间隐藏底部导航；本地 Pikafish 优先应招，云库及保存题解作为明确标识的备用。支持题解外合法走法、失败重试和红／黑先行，绝杀、困毙显示获胜方并停止应招。
- 平板导航默认底部，保留明确保存的导航选择；改善 iPad 作业与横屏布局。
- 优化轻点、拖动、重复点击与引擎评分／候选区域滚动。
- 年度杀法题库分组、具体杀步筛选、联网核对其他正确解法，修正教学题解解析版本。

教师统计、学生身份和逐题成绩回放属于 1.0.3，未作为新功能重复列入。
