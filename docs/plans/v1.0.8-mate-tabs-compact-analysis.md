# 杀法步数多选与拆棋引擎紧凑布局

2026-10-29；基线 `0e2c9179`，后台工作树基线 `aec4e90`。

## 本轮改动

- 共用选题组件将步数下拉改为可多选标签：全部、一步杀、两步杀、三步杀、四步及以上。多选取并集；全部或取消最后一项恢复不筛选。进入书本、返回及翻页保持条件，改变筛选取消旧请求并重置分页。
- 服务端新增 `mateSteps=1,3,long`，校验、规范化并绑定游标，沿用当前有效杀棋证明、发布版本及机构权限过滤。保留旧 `mateMoves`/`mateGroup` 和 `mateFilterVersion:1`，增加独立 `mateMultiFilterVersion:1`，兼容已安装 10089；旧服务端多选明确提示不支持。
- 拆棋/录谱共用引擎面板精简标题、参数行；候选着法按内容排版，不再平均拉高。小棋盘与为什么推荐放入一行，工具按钮不再继承着法网格样式。
- 拆棋研究区底部固定保留 44px 分支停靠区，有无分支高度一致。浮层默认位于候选滚动区域外，可继续拖动、收起；不改变主线、注释、存储或原生命令。

## 验证

- 移动端 UI 152 项、逻辑 61 项通过；后台服务端 95 项通过、17 项忽略。本地一次性 MySQL 验收通过，覆盖并集分页、规范化游标、切换条件拒绝旧游标和权限/有效证明边界。
- Chromium/WebKit：步数标签多选 320/360/390/430/1024px；紧凑候选卡、双操作同排、候选区域外分支停靠、0/1/3 个分支下棋盘几何差异不超过 1px，覆盖 320×740、390×844、430×932、844×390、1024×768。
- Chromium/WebKit 接续回归：5/5 → 保存四步 → 5/9 → 下一步/播放 → 重载；嵌套分叉、原主线与注释不变、桌面 IndexedDB 和手机 localStorage 保留。
- 浮层回归包含手机六按钮、0/1/2/10 分支、展开收起、拖动、内部滚动，桌面简洁/专业主题；最终结果以发布补记为准。
- 前端构建及共用创作组件同步检查通过；未修改 Rust 原生接口。
