# 1.0.8 推演引擎与删除变招

用户确认的范围：去掉移动棋谱面板“棋谱与注释”标题和逐步“讲解”按钮，保留着法、分支及注释编辑。移动端与桌面端小棋盘同步显示谁优、计算深度、节点、耗时、回合；AI 提示关闭时只隐藏候选与箭头。点候选可在临时棋盘走一步，合法性仍需校验；点击保存才写谱。临时线路和已保存变招都可删除，已保存删除需明确确认，保留主线及其他分支。临时内容与已保存内容分别操作。

小棋盘每个停留局面做一次 1.5 秒搜索，三条候选；播放和收起时暂停，更多菜单可暂停/恢复计算。移动端复用本地引擎协调器，Web 使用既有登录分析接口。桌面预览搜索独立进程，不发主棋盘事件、不存分析数据。过期请求不回填；评分统一转为红方视角。节点未提供时显示“—”。

保存变招管理在小棋盘“更多”中，逐条列出真实变招记录，避免把共同首着当成同一可删分支。只读棋谱需复制，切换账号或来源后禁止误删旧来源。
