# 1.0.8 小棋盘推演与保存分支

来源：本次用户确认的计划及视频。移动端与桌面端同时实现，增强现有拆棋、研究、录谱，不新增布局体系管理页面。

## 用户确认的行为

- 候选打开独立小棋盘，载入完整合法 PV，不限制为原有8回合；冻结本次候选，后续引擎结果不替换它。工具区另有自由推演入口。
- 顶部固定标题、保存整条线路及总步数、更多、收起、关闭。底部有起点、前后步、播放暂停、终点、进度。一步为一方走一次。
- 手机悬浮可拖动收起展开；桌面默认并排，可切为应用内悬浮、拖动缩放。面板在视口内，顶部可操作。沿用棋盘皮肤、简洁浅色和专业暗色。
- 手动合法走子；回看中途改走保留原线路，保存新线路到推演终点，不拼接旧后续。收起暂停并保留会话；关闭未保存内容提供保存、放弃、继续研究。
- 默认保存当前选中线路全部步骤，和当前回放位置无关。更多中的保存至当前步只保存前缀，起点不可用。只保存当前线路。
- 保存后大棋盘不动，小棋盘保留；更新分支标记并可显式查看已保存分支。
- 相同父节点与走法复用，共同前缀复用；重复点击/重试不重复建分支。不替换原主线、注释、其他分支或学生成绩。
- 临时预览不写原谱；完整校验后整批原子保存，失败保留线路可重试。
- 来源绑定棋谱、节点/完整路径、局面、上下文。主谱导航不改变来源；换谱、起始局面变化、节点删除后禁止写回旧来源，可另存。忽略过期异步结果。
- 只读来源复制到我的棋谱后保存。自由拆棋首次持久保存使用原有标题与目录弹窗，保留原谱完整内容和新增分支。
- SQLite 节点和 outbox 事务写入；手机使用原生存储整条记录原子提交；Web使用IndexedDB适配。不新增服务端业务接口。不使仅添加侧枝的主线报告失效。

覆盖长线路、黑先、FEN、续走与改走、重复及前缀保存、嵌套分支、来源失效、只读复制、故障重试和重启恢复；双端界面测试、逻辑测试、Rust事务/棋谱测试、两端前端构建和Rust检查。检查手机触控/安全区/横竖屏与桌面两种主题/面板边界。
