## 实现约束

- 选题先选题库/书本，再分类、搜索、翻页、查看或选择题目。列表卡片不得被纵向 flex 压扁，棋盘缩略图必须在行内；后台共享四文件必须一致。
- 候选区始终占位，关闭 AI 隐藏候选及箭头，保留局势和深度、节点、耗时。长指标不换行；计算失败和重试共用固定候选槽。校验、保存和失败消息使用固定通知槽，不能移动或遮挡棋盘。
- 当前局面有多个真实下一着时，按照同一去重顺序显示橙色编号箭头、绿色编号按钮、主线/分支标记；点击只进入对应第一着。允许收起后恢复；手机管理入口复用现有棋谱编辑。
- 保存保持真实和临时棋盘位置；查看已保存分支显式返回来源局面后选择，不跳到线路末尾。同局面其他走法、主线及注释保留，重复保存不重复写入。
- 本轮没有原生或服务端接口变更。后台选书接口/共享界面已在私有发布分支 `9265293`/`96eac35` 实现并上线；本地四文件校验一致，无后台待提交修改。
