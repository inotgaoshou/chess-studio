## 真实页面操作

`scripts/test-variation-board-ui.cjs` 使用隔离 API fixture、真实 App/WASM/存储和 CSS；不会连接生产业务接口。先启动两端 Vite，再运行：

```sh
PRACTICE_URL=http://127.0.0.1:1422 DESKTOP_URL=http://127.0.0.1:1421 node scripts/test-variation-board-ui.cjs
```

已在 Chrome 无头浏览器通过：

- 手机临时走子不写原谱；停在起点保存整条线路；重复保存复用；主线、注释和当前步保持不变；后续大棋盘自动保存保留新增分支。
- 手机 390×844、844×390、820×1100 触控视口，拖动、收起、展开、旋转和操作区边界；标题资料弹窗位于小棋盘之上。
- 只读谱复制成可写个人棋谱，原始记录完全不变，主线与注释保留。
- 自由拆棋先有 A 线路，打开小棋盘试 C，收起后大棋盘改走 B，首次保存同时保留 A/B/C；大棋盘位置保持不变。
- 保存过的会话在新建同 FEN 棋局后拒绝默认写回，临时线路保留且可显式另存。
- 桌面使用真实 WASM 与 IndexedDB：保存、重复合并、原注释和位置保留、副本不激活、页面重载恢复；非法线路不产生局部写入，删除的锚点不能保存。
- 桌面简洁浅色与专业暗色，并排/悬浮及窗口缩小后的面板边界。

浏览器验收不替代 iPhone 实机的原生触控/安全区验收，亦不替代 Tauri 壳的原生窗口验收。这两项尚未实测；本轮未安装手机应用或发布桌面安装包。
