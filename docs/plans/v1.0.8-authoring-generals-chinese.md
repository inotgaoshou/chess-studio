# 1.0.8（10092）摆棋将帅保护与中文着法

2026-10-29，基线 03d248b4；后台基线 d43fb65。

- 棋子栏移除黑将、红帅，仅保留每方六类普通棋子。清空保留棋盘上的两将帅；将帅不能删除或被放置/移动的其他棋子覆盖。直接点将帅进入移动，仅限己方九宫。翻转沿用逻辑坐标，撤销清除旧选中点。
- 识别/旧草稿缺将帅时提供“补齐将帅”；只在空的己方九宫交点补入，不覆盖其他子，保留先走方。识别重复将帅可删除多余的一枚，最后一枚受保护；缺将帅时不能完成摆棋。
- 答案/回放/教师试做中的后续着法统一使用实际当前局面生成的中文记谱。服务端原 board 响应新增 moveNotations，保留 fen/legalMoves；复用 Rust 棋规记谱，支持黑先、自定义局面及前后子区分。前端按起始 FEN + 当前路径绑定响应，忽略过期结果，未核对的着法禁用且不回退为坐标代码。棋谱存储和 API 落子数据格式保持原有方式。
