# 1.0.8（10092）摆棋将帅保护与中文着法

2026-10-29，基线 03d248b4；后台基线 d43fb65。

- 棋子栏移除黑将、红帅，仅保留每方六类普通棋子。清空保留棋盘上的两将帅；将帅不能删除或被放置/移动的其他棋子覆盖。直接点将帅进入移动，仅限己方九宫。翻转沿用逻辑坐标，撤销清除旧选中点。
