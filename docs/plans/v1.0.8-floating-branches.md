# 1.0.8（10088）分支悬浮与布局稳定

## 范围和验收要求

基于 e77ecda2，在移动端和桌面端共用 BranchStrip 实现悬浮分支选择。分支不占棋盘网格或底部工具区；零、一、多条后续以及展开、收起、拖动和选择时，相同视口下棋盘/固定工具栏几何变化应不超过 1px。

- 手机竖屏六个快捷按钮（AI、自由推演、分析、新增棋谱、摆棋、信息）固定一行，320px 不换行、不横滚；横屏侧栏三列两行。
- 手机状态提示固定高度、长文字省略。棋盘继续随实际视口自适应。
- 没有后续隐藏；单条显示“继续：首着”；多条按现有顺序自动显示编号和着法，编号对应棋盘箭头。
- 点击进入该分支第一步，新局面分叉自动展开；同局面普通刷新不打断收起状态。下一步重新展开；播放遇分叉暂停选择。
- 可拖动/收起，无全屏遮罩；卡片不遮工具栏，安全区与视口约束，最多两列、内部滚动。导航/保存/引擎刷新保留拖动位置，旋转/缩放时校正。
- 菜单、编辑弹窗与展开的小棋盘隐藏选择；小棋盘收起后可继续选择。桌面管理变招沿用编辑操作，但用独立居中弹窗防止被菜单栏覆盖；下一步/播放使用同一个悬浮选择。
- 不修改主线、分支顺序、注释、存储格式、原生命令或服务端接口。

## 实现

BranchStrip 通过 portal 将卡片放入独立的固定悬浮层，几何约束由 branchOverlay 计算；两端传入棋谱/局面身份及实际棋盘、工具栏边界。局面身份与显式唤起计数区分自动展开和普通刷新。VariationBoard 回传收起状态，避免与展开的推演面板相互遮挡。桌面菜单回传打开状态。
