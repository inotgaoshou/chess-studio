# 1.0.8 小棋盘布局与分支入口验收

日期：2026-10-29。基线：`e084fadc`；分支：`codex/v1.0.8-training-terminal`。

本轮按参考视频收紧小棋盘布局，保留现有皮肤与主题。未部署服务端、发布正式安装包或创建备份。按用户最新要求先在 iOS 模拟器验证，未覆盖安装到 iPhone 14。

## 实现

- 手机默认宽度为 80vw、最大 360px，初始靠右下；顶部单行显示小棋盘、保存、更多、收起和关闭。窄屏保存按钮保留无障碍名称。
- 棋盘落点不再继承工具按钮的边框、底色及内边距；棋子比例与主棋盘一致。主体保留棋盘、步数、细进度条及五个图标回放按钮。
- 更多菜单容纳完整谱名、着法、临时线路、翻转、展开及保存至当前步。收起暂停播放，恢复保留会话。
- 保存整线后继续留在当前研究位置；重复保存提示“该线路已保存”。失败重试保留原保存范围与副本目标。
- 两端主棋盘下方显示按原顺序排列的编号分支入口，同一下一着只显示一次。点击只导航，不提升主线或改变分支顺序。
- 手机导航保存规范主线与显示线路的区别，保存后复用原生存储返回的分支 ID；删除正在浏览的分支不会重新生成它。
- 模拟器发现 WKWebView 横屏转回竖屏后棋盘尺寸与 Grid 居中位置更新异常，导致棋盘裁切。改用 ResizeObserver 测量内容区域，同时约束棋盘宽高，并改用 Flex 居中，避免残留旧列宽；收起恢复时重建观察器。
