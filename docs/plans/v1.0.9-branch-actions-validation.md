# 分支显示与操作验收（2026-10-31）

## 变更

- 移动端分支箭头、编号及按钮使用同一组分支颜色；1、2 默认深橙、蓝。编号顺序继续来自当前局面的真实后续走法。
- AI 提示与分支编号共用避让算法，优先放在棋子旁的空隙，用细线对应原走法。翻转时使用翻转后的棋子位置计算。
- 浮动分支条的“管理变招”打开按编号列出的编辑／删除面板；只剩一条后续时仍可管理。
- 编辑导航到所选线路第一步，继续走棋；注释仍通过棋谱面板修改。只读来源禁用修改。
- 删除前明确提示所选着法及后续。按完整路径删除子树，保留其他分支和可达注释；删除主线后续时仅缩短主线，不自动把其他变招设为主线。
- 录谱删除在一次存储写入成功后更新界面；校验会话和源棋谱是否变化，保存失败保留当前棋谱并允许重试。拆棋使用已有本地状态保存。
- 拆棋顶部纸笔按钮改为“新建棋谱”，每次创建独立身份的标准开局空白棋谱，防止连续点击重复创建。原来的棋谱仍保留。
- 上一提交已完成选题列表每页 50 题与跨页选择，本轮未改变该行为。
