# v1.1.0（10133）学习路线、题号与默认数字导航

## 本轮范围

- 学习路线仅在登录后展示，未登录时提供“登录后查看学习路线”入口。
- 路线动作明确标注目标，例如“基础杀法 › 3步杀”“实用残局 › 求和防守”。进入前按实际账号权限与筛选请求核对可用题目；无结果或返回范围不符时保留面板并说明，不回退到无关的全部题目。连续点击、关闭、切换路线、退出账号时取消旧请求。有效首批结果复用，不重复请求。
- 题库卡片、做题和结果页统一当前列表序号。修复“第 2 题 · 第 1 题”等重复标题；有实质名称时保留名称，原书题号放在独立来源说明中。存储标题不变，跨页去重和每组 20 题的范围沿用原规则。
- 杀法与残局等做题页默认展开本组数字导航，位于棋盘下方的操作滚动区；支持点数字跳题、收起与展开，记住设备上的显示偏好。原题目目录仍可查看组数、总题数并切换组。
- 数字导航同时表达“当前题”和结果：`✓ 已完成`、`阅 已看解析`、`… 待复核`。服务端尚未确认的本地通过不计入已完成数。看解析不代表答对或掌握。
- 老师试做标记写入现有本机进度记录，按账号、服务、机构及题目内容隔离，切题和重载保留；更改题目内容后清除旧标记。沿用最近 100 条本机进度容量；不新增服务端成绩或表。普通本地练习复用已有答题历史；记录结果不清空未完成草稿。

本轮不部署服务端，不上传或替换商店审核构建，不卸载，不备份，不推送 Git 远端。

## 原因与回归

原题号清理函数在清理结果为空时恢复原标题，调用方又加上列表序号，导致双题号；老师试做目录只判断当前题结束状态，导致离开该题后已做标记消失。修复为统一的题号标签与来源说明，并从现有记录读取结果状态。

- 新增回归先复现做题标题“第 22 题 · 第 22 题”，及当前题无法同时表达已完成状态，修复后通过。
- 移动端逻辑测试：67 项通过。
- 移动端界面测试：36 文件、236 项通过。
- TypeScript 与 Vite 生产构建通过。
- Chromium / WebKit 均覆盖 320×740、390×844、430×932、844×390、820×1180、1180×820：默认数字导航、展开/收起、完成/解析/待复核标记、21–40 / 41–50 分组、前后组切换及会话复用通过。收起/展开前后棋盘和固定导航的 x/y/width/height 偏移均不超过 1px。
- 两种浏览器均验证老师试做查看解析后切题、返回、重载保留标记，以及题解内容变更后标记重置；未请求学生成绩写入接口。
- 学习路线两种浏览器六尺寸验证准确筛选、范围说明、书本目录和匿名登录入口；UI 测试另覆盖空结果、服务端忽略筛选、重复点击、退出登录、取消和迟到响应。

以上浏览器检查使用隔离的授权接口样例，不将样例通过视为真实线上题目归类或题量已审计。线上数据库本轮未修改；真实账号题库的内容需要在手机进一步查看。
