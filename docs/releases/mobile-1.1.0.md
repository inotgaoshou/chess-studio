## 用户可见更新

- 题库每页 50 题，练习和数字导航每组 25 题；展示总题数、页数、当前组与总组数，导航可收起并吸顶，练过/完成状态有标识。
- 个人题库与机构作业库分开管理；筛选直接展示棋盘题目，跨页选择去重。保存目录后立即返回，后台刷新不阻塞；目录删除只移除引用，保留原题和历史作业。
- 题库首次筛选、来源缓存与目录读取提速；按当前验证步数筛选，不凭书名推断。发布作业继续由老师核对并主动确认。

- 题库新增杀法与残局学习路线入口：按阶段查看观察方法、自查要点并进入现有题库；复用步数、胜和目标、兵种与书本筛选，沿用账号权限和空目录提示。路线可自由选择，不代表自动掌握度。
- 杀法与残局共用紧凑做题布局、大棋盘比例和题号入口；补充目录、组数与总题数。棋盘固定，下方操作、说明与题解独立滚动。
- 题内“学习思路”面板整合观察方法、原有三级提示、已有题目讲解和遮住解析重做，不提前泄露受限答案，不重置练习记录。
- 题解单步与播放复用落子、吃子、将军、绝杀和困毙反馈；说明按段落与重点排版，支持中文朗读、停止与语速选择。切题、关闭、后台与迟到响应隔离。
- 录谱 AI 按“禁用 → 局势 → 提示 → 局势 → 禁用”循环，评分与推荐展示一致；独立分析布局与录谱共享棋谱状态，并保留原有菜单功能。
- 录谱/拆棋提供闪电出招：复用当前第一候选或等待当前计算，只走一步；导航和切换局面取消待执行动作，经过正常合法性检查及保存流程。
- 棋盘顶部对齐、按钮与分析区域更紧凑；提子厚度、倾斜和分离阴影优化。分支使用细橙色流水箭头、绿色编号，编号优先靠近箭头杆；保留分支编辑、删除、排序和非破坏性导航。
- 困毙参考声线调整仍显示准确的“困毙”文字。音频生成素材与脚本保留以便复现；最终听感需要真机确认。
