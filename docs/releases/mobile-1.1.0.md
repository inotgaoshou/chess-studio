# 棋析 v1.1.0（10135）

## 版本与范围

本次将当前移动端改动统一整理为 **1.1.0**，Android `versionCode` 与 iOS `CFBundleVersion` 当前均为 **10135**（首个 1.1.0 构建为 10131）。同步更新前端包版本、两端原生默认版本及构建脚本默认值，正式配置连接 `https://api.qixiapp.cn`。

本轮构建、提交代码和覆盖安装手机测试，不上传商店、不替换审核构建、不卸载、不创建备份。10135 经用户另行授权，仅发布服务端 25 题兼容修复；线上接口性能排查与无用产物清理另行记录。桌面主应用版本保持独立管理。

最新 10135 将题库按每页 50 题、导航和练习每组 25 题展示，显示总题数、页数、组数；数字导航滚动到顶部后固定，展开与收起均保持吸顶。具体范围、安装和线上限制见 [10135 验收记录](v1.1.0-10135-pagination-groups.md)。10134 将数字导航移到外层，做题页保留前后题及下拉目录，见 [10134 记录](v1.1.0-10134-catalog-number-navigation.md)。此前学习路线准确跳转、登录限制、重复题号和练习状态修复见 [10133 记录](v1.1.0-10133-route-numbering.md)。

## 用户可见更新

- 题库新增杀法与残局学习路线入口：按阶段查看观察方法、自查要点并进入现有题库；复用步数、胜和目标、兵种与书本筛选，沿用账号权限和空目录提示。路线可自由选择，不代表自动掌握度。
- 杀法与残局共用紧凑做题布局、大棋盘比例和题号入口；补充目录、组数与总题数。棋盘固定，下方操作、说明与题解独立滚动。
- 题内“学习思路”面板整合观察方法、原有三级提示、已有题目讲解和遮住解析重做，不提前泄露受限答案，不重置练习记录。
- 题解单步与播放复用落子、吃子、将军、绝杀和困毙反馈；说明按段落与重点排版，支持中文朗读、停止与语速选择。切题、关闭、后台与迟到响应隔离。
- 录谱 AI 按“禁用 → 局势 → 提示 → 局势 → 禁用”循环，评分与推荐展示一致；独立分析布局与录谱共享棋谱状态，并保留原有菜单功能。
- 录谱/拆棋提供闪电出招：复用当前第一候选或等待当前计算，只走一步；导航和切换局面取消待执行动作，经过正常合法性检查及保存流程。
- 棋盘顶部对齐、按钮与分析区域更紧凑；提子厚度、倾斜和分离阴影优化。分支使用细橙色流水箭头、绿色编号，编号优先靠近箭头杆；保留分支编辑、删除、排序和非破坏性导航。
- 困毙参考声线调整仍显示准确的“困毙”文字。音频生成素材与脚本保留以便复现；最终听感需要真机确认。
