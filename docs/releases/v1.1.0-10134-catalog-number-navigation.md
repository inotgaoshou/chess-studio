# v1.1.0（10134）数字导航移至题目列表

## 行为

- 移除做题棋盘下方的数字网格。保留顶部上一题、下一题、题号下拉，以及原分组目录。
- 在杀法、残局等手机题库的筛选区下方、题目卡片列表上方，统一显示数字导航。默认展开，可收起，设备记住本次偏好；旧的做题导航收起状态不影响新入口。
- 每组最多 20 个已加载题号，支持题号范围、上一组、下一组。明确区分已显示题数与总数；只能定位已加载题目，更多内容仍通过列表底部的下一页读取。
- 点数字定位并聚焦对应卡片，点卡片才进入练习，不因浏览数字创建练习、添加题目或发布作业。保留列表顺序、当前筛选、原题号来源和已有选题/组装规则。
- 标记使用当前账号已知的练习结果，老师试做沿用本机账号记录；没有已加载记录的学生题目不伪造已做/未做状态。当前会话的已完成、已看解析、待复核状态在返回外层时可展示。
- 原“按题号浏览”按钮更名“全部步数”，明确其实际作用是清除杀法步数限制，避免与数字导航混淆。
- 隔离目录通用按钮样式，避免较大内边距挤压两位题号换行。

未修改服务端接口、数据库或原生命令；不部署线上、不上传商店、不卸载、不备份、不推送 Git 远端。
