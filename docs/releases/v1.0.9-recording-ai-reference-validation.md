# v1.0.9 录谱 AI、独立分析页与提子效果验收

日期：2026-11-01。范围：手机与 iPad 前端及相关验证脚本。

## 使用与行为

- 录谱 AI 按钮初始为禁用，循环为 **AI 禁用 → AI 局势 → AI 提示 → AI 局势 → AI 禁用**。内部保留四个阶段；两次局势的下一阶段不同。
- 禁用停止计算并隐藏评分、推荐；局势显示优劣和计算信息；提示同时显示推荐与箭头。局势／提示切换复用分析任务和结果，已有棋谱分支选择独立保留。
- 点击“分析”进入独立分析布局，复用当前棋谱、节点与保存状态。从禁用进入时切至提示；返回录谱后保持最后的阶段。分析页底栏提供菜单、新增、翻转、AI 模式、上一步、下一步，其他录谱功能保留在原界面或菜单。
- 分析页包含引擎／云库／棋谱页签。点候选只高亮；点“小棋盘”进入临时推演。自动分析沿用局面防抖、过期结果隔离和引擎占用协调。
- 选中棋子轻微倾斜、抬升，显示侧面厚度与右下分离阴影，不增加选中圆环。拖动、放下和取消清除旧位置效果；小棋盘减弱提起幅度，减少动态效果时取消过渡。
