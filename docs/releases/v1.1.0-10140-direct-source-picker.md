- 从平台／机构题库选题直接进入棋盘缩略图网格；“全部”、一步、两步、三步、四步及以上均直接查询题目，不再要求选择书本。
- 步数筛选常驻顶部；分类和名称搜索仍可按需展开。保留50题分页、跨页全选、重复拦截、单目录1000题上限、详情及主动确认添加，返回直接退出并丢弃未确认选择。确认添加不会发布作业。
