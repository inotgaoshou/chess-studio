# v1.1.0（10140）筛选后直接选题

- 从平台／机构题库选题直接进入棋盘缩略图网格；“全部”、一步、两步、三步、四步及以上均直接查询题目，不再要求选择书本。
- 步数筛选常驻顶部；分类和名称搜索仍可按需展开。保留50题分页、跨页全选、重复拦截、单目录1000题上限、详情及主动确认添加，返回直接退出并丢弃未确认选择。确认添加不会发布作业。
- 现有棋谱导入继续按棋谱库浏览；目录和题目原数据保持不变。
- 跨题库查询原来逐题使用完整证据关联子查询，生产两步／四步以上筛选都超过12秒。改为最多1000个候选的有界证据关联，复用当前来源版本、指纹和验证步数谓词，权限和去重规则不变。
- 无新增接口、表或原生命令；手机和后台共用选题实现。
