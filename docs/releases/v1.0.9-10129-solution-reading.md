# 1.0.9（10129）题解回放、朗读与固定棋盘

## 问题与修改

只读题解 `SolutionReadPanel.go` 与做题后 `previewAnswerStep` 原来仅替换棋子、着法和步数，未产生共用走棋反馈事件，因此没有声音和走子动画。浏览器回归先通过真实题解“下一步”复现没有移动棋子的失败。

- 两个入口复用现有回放事件：前进一步播放落子、吃子、将军、绝杀或困毙音效及动画，使用原音频资源；后退、起点及多步定位不补播旧音效。吃子/终局预留反馈时长。
- 题解读取校验请求代次、题目/会话及账号权限；关闭、切题、暂停、后台取消过期任务与声音。播放结束可从头重播。
- 新增共用 `SolutionExplanation`：当前着法与题目说明分区、段落与重点展示，安全解释导入数据中的 BBCode，不把 `[b]` 原样显示或插入 HTML。
- “朗读说明／停止朗读”和慢速、正常、快速语速，复用现有 iOS/Android 离线中文语音桥。只读当前说明，切步、切题、关闭或后台停止；朗读与走棋播放互斥。无可用语音时显示原因并可重试。
- 做题页棋盘、题号和计时区固定，下方操作、结果、学习思路、题解及说明独立滚动。正常手机宽度优先，短屏按固定视口预留阅读区；横屏/宽屏内容在侧栏滚动，不随提示或判题缩放。
- 只读弹窗保留固定棋盘及播放区，增加说明区可读高度，仍只滚动下方详情。
