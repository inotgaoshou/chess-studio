# v1.1.0（10135）题库分页、25 题分组与吸顶导航

## 行为

- 杀法、实用残局等题库每页显示 50 道题，使用上一页、下一页和已读取页码选择；前页复用已加载内容，翻页保留全局题号，筛选改变后回到首页。
- 导航及每轮练习统一每组 25 题，一页两组，末组按实际数量显示。列表显示总题数、总页数、总组数与每组数量；总数尚未返回时明确显示待统计，不将已加载的 50 题冒充全部。
- 外层数字导航默认展开、可收起，滚动至应用标题栏下方后吸顶。卡片列表继续滚动；折叠和展开后的题号定位均避开导航区域，横竖屏重新测量。
- 数字定位只定位题目卡片，不创建练习；点卡片进入对应 25 题组。保留跨组导航、已有会话、当前题和已知成绩标识。
- 分页请求去重，检查游标循环、筛选代次及取消信号；迟到结果不能覆盖新筛选。
