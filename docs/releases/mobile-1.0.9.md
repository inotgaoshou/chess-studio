# 棋析移动端 1.0.9 更新与提审准备

对比基线：已发布 iOS 1.0.8（10092），功能源码 `8155330c`；本次准备 Android 1.0.9（10106）。小棋盘、极速出招、保存分支、AI 提示开关和将帅保护在 1.0.8 已有，本版不重复列为新增。

## 与 1.0.8 的主要区别

| 范围 | 1.0.9 变化 | 使用方法 |
| --- | --- | --- |
| 我的题库 | VIP 与老师可管理个人私有目录、题目；老师可明确复制到机构作业库，个人与机构权限隔离 | “我的 → 我的题库”；老师也可从教师工作台进入 |
| 布置作业 | 目录优先，平台作业库、我的作业库与已发布作业分开；先选题，再选学生，最后核对发布 | “教师工作台 → 我的作业库 · 布置作业”；确认添加只添加题目，不会自动发布 |
| 选题与分页 | 杀法步数单选，每页 50 题，上一页／下一页；显示当前筛选的总题数、总页数；复用有效核验缓存 | 选书本后打开“筛选”；底部查看页数和总数，勾选后主动确认添加 |
| 杀法练习 | 修复一步、三步、四步杀缺少可练题；保留已发布与强制杀验证要求 | “杀法练习”切换对应步数；这是线上题库修复，旧客户端也可受益 |
| 背谱 | 修复练习方、自动应手、错着保持原局面、提示与练习进度恢复 | 打开有走法的棋谱，菜单选“背谱练习”，选择练习方 |
| 推演 | 小棋盘打开时继承主棋盘观看方向，允许单独翻转；进一步完善手机、iPad 布局 | 打开“自由推演”或候选小棋盘，点击顶部翻转按钮 |
| 棋盘与反馈 | 默认竹韵皮肤改善棋子边缘、厚度与阴影；完善上一着标记、走子、吃子、将军、绝杀和困毙的反馈 | 现有练习、录谱、拆棋流程直接生效；其他皮肤保留 |
| 分支研究 | 编号与不同走法更易区分，数字避让棋子；可管理指定分支、删除时确认并保留其他线路 | 点分支入口选择走法，进入分支管理后编辑／删除；纸笔按钮新建空白棋谱 |
| 题解回放 | 下一步、自动播放、分支和长讲解不再挤压棋盘及固定按钮；字体、间距更紧凑 | 题目卡片点“看题解”，再使用下一步／播放／分支按钮 |

## 本轮验证与交付范围

- 手机与后台共用选题组件，显示服务端筛选、去重后的总数，不以当前页条数代替总数。
- 题库缓存仍先校验访问权限；修订、下架后失效；跨机构隔离、分页和并发场景由临时数据库验收覆盖。
- 选题组件 32 项 UI 测试通过。题解回放此前已完成 Chromium/WebKit 手机、横屏和平板布局回归，见 `docs/plans/v1.0.9-solution-read-layout-validation.md`。
- 已安装 iPhone 版本为 1.0.9（10105），启动与重启已验证；本轮新增总数显示需更新客户端后生效。真实触控、听音和全部视觉效果不能以浏览器自动化代替。
- APK 使用正式接口配置、release 签名，并核对版本、资源、内置引擎与许可证。最终制品及性能实测见本次交付记录。
