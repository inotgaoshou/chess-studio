# 1.0.9（10113）录谱自动分析与紧凑布局

本轮基线：`df8792c2`。本包用于覆盖安装验收；不替换正在审核的 1.0.9（10112），不更新线上服务，不卸载或备份手机数据。

## 实现

- 录谱开启 AI 后，局面稳定 300ms 自动分析；落子、导航、分支切换及参数修改均刷新建议，不自动落子。
- 结果绑定账号范围、棋谱身份、会话代次、FEN、棋规及参数。每个任务有独立 AbortSignal；旧结果、旧箭头和旧推演候选不可复用到新局面。
- 小棋盘、背谱、讲解和报告占用期间暂停主分析；网页 visibility/pagehide 与 Capacitor 原生 pause/resume 均处理暂停恢复，只重算当前局面。
- 录谱采用固定顶部工具栏、棋盘、五个回放按钮、棋谱/云库/引擎页签和固定状态区。内容内部滚动；宽屏/横屏内容放在棋盘侧边。
- 顶部纸笔移除；新建、保存、收藏、导入、背谱、讲解、报告、注释与变招及设置放在更多菜单。拆棋顶部纸笔同样移入更多。
- 录谱云库按当前 FEN 查询，显示加载、空结果和错误重试，复用现有接口。
- 未修改棋谱存储格式、主线或分支规则，无新增服务端接口、数据库字段及原生命令。
