# 1.0.9（10122）棋盘顶对齐与参考局势条

日期：2026-11-01。

用户反馈：棋盘在上方局势条与底部工具区之间垂直居中，产生明显空白，与参考棋者布局不符。

## 修改

- 录谱、独立分析页和拆棋棋盘改为顶对齐；录谱／分析棋盘与顶部局势条间隔不超过 4px。保留棋盘比例、原皮肤和触控交叉点，短视口仍根据可用高度缩小。
- 独立分析页收回原先棋盘上下居中的余量，将空间留给引擎候选等内容。
- 局势条改为整行红黑比例背景，左侧显示深度、节点与速度，右侧显示红黑优劣；仍复用原红方视角评分换算。禁用、等待、失败和计算完成共用固定高度，不因状态变化移动棋盘。
- 默认录谱保留当前内容面板展开／收起状态、六个快捷按钮、回放和分支浮条；不更改主线、保存规则或服务端接口。

## 验证

- 13 项相关移动端界面测试通过，包括旧 iOS 可用尺寸适配与新增顶对齐短视口测试。
- Chromium／WebKit 各覆盖 320、390、430px 手机、手机横屏及 iPad 横竖屏。新增断言要求棋盘贴齐可用区域顶部，紧接局势条，页签／AI 模式切换时棋盘和固定工具栏偏移不超过 1px；自动分析与棋谱内容保持回归通过。
- 拆棋六种视口及三个页签在 Chromium／WebKit 中通过顶对齐、视口边界和面板无遮挡检查。
- 移动端生产环境构建、签名、包内 Web 资源一致性及新功能内容校验通过。实际入口：`index-Z-4E2xVU.js`、`index-F-mqQCzt.css`。
