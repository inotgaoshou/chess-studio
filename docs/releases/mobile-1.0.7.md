# 棋析移动端 1.0.7 与 1.0.6 的差异

基线：正式标签 `v1.0.6`（`4606b3ea`）。本次候选为 Android、iOS 1.0.7 / 10070，正式服务 `https://api.qixiapp.cn`。2026-10-27 只读核实 App Store Connect：1.0.6 / 10054 可分发，TestFlight 最高已上传构建为 10054，尚无 1.0.7；本地既有候选最高为 10069，故递增至 10070。

| 方面 | 1.0.6 | 1.0.7（Android / iOS 共用） |
| --- | --- | --- |
| 着法教学 | 无本轮教学面板 | 历史着法“讲解这步”、候选“为什么推荐”，有题解权限时可解释 AI 应手；依据本地事实及引擎参考变化 |
| 中文朗读 | 已有落子反馈音 | 手动朗读、停止及语速调整；系统离线普通话，缺声音保留文字，不申请麦克风权限 |
| 讲解表达 | 无对应功能 | 中文棋谱替代 ICCS 显示；精简局面问题及作用；变化标记红黑双方，最多 12 次落子 |
| 判题 | 已有皮卡鱼复核及待复核 | 杀棋及残局取胜要求实际终局；净得子核对回吃后收益；平台题缺审核目标不直接判完成 |

| 录谱学习 | 已有打谱、分支及学习 | 紧凑工具栏、完整树导入、背谱练习、分支编辑及返回位置恢复 |
| 操作响应 | 已有加载提示与进度恢复 | 历史后台读取；恢复棋盘不等待线路复核结束；优先显示落子，阻止迟到结果覆盖新页面 |

## 平台差异

- Android：签名 APK 内测，Android 10 / API 29 起，仅 ARM64；使用 Android TextToSpeech 已安装的离线中文声音。保持既有签名以支持覆盖安装。
- iOS：最低 iOS 15，支持 iPhone / iPad；使用 AVSpeechSynthesizer。完成提审门槛后直接提交审核，通过后手动发布。
- 基础本地棋谱及分析可离线；平台取题、登录及师生作业仍需网络。讲解未接大模型，不读取引擎内部思维，不改棋谱树、评分及历史成绩。

## 发布说明边界

不将浏览器模拟接口的速度当作公网真机表现；不承诺所有接口低于一秒。不将本地审核的 5000 题写成已上线题量。不将原有作业、打卡、皮卡鱼或 iOS 15 支持重新宣传为本版新增。
