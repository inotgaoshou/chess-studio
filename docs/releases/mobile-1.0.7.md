## 10079 重新提审更新（2026-10-28）

本次改用 iOS 1.0.7（10079），基于当前工作树生成正式 Release Archive，连接生产 API。新增教师机构题库、摆棋与连续录题、答案校验及目录布置作业；完善题目来源搜索、分类筛选、重复来源展示和冷启动等待；完善实用残局／中局按书本学习、残局筛选和题号定位、飞刀教材入口；修复教师打卡布局并增加作业概览详情入口。

版本文案、完整商店描述与审核备注位于 `../../app-store-assets/qixi-review-1.0.7-10079/`。照片上传与识别用途已补入中英隐私政策；商店隐私标签声明六类数据，均用于 App 功能、与用户身份关联，不用于追踪。仅发布静态政策页，未部署后台/API。

验收及最终审核状态见 `../acceptance/mobile-1.0.7-10079-release.md`。

## 平台差异

- Android：签名 APK 内测，Android 10 / API 29 起，仅 ARM64；使用 Android TextToSpeech 已安装的离线中文声音。保持既有签名以支持覆盖安装。
- iOS：最低 iOS 15，支持 iPhone / iPad；使用 AVSpeechSynthesizer。完成提审门槛后直接提交审核，通过后手动发布。
- 基础本地棋谱及分析可离线；平台取题、登录及师生作业仍需网络。讲解未接大模型，不读取引擎内部思维，不改棋谱树、评分及历史成绩。

## 发布说明边界

不将浏览器模拟接口的速度当作公网真机表现；不承诺所有接口低于一秒。不将本地审核的 5000 题写成已上线题量。不将原有作业、打卡、皮卡鱼或 iOS 15 支持重新宣传为本版新增。

测试与提审状态见 `../acceptance/mobile-1.0.7-10070-release.md`；商店文字见 `../../app-store-assets/qixi-review-1.0.7-10070/`。
