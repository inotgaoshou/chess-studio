# 1.0.9（10114）录谱入口、做题布局和困毙反馈

## 变更

- 恢复用户截图中的录谱界面：标题和棋库入口、六个常用按钮、菜单／上变／上一步／播放／下一步／下变／翻转／报告。保留导入、保存、收藏、背谱、讲解、注释与分支编辑等入口。
- “分析”开启随局面自动更新的引擎页签。默认不预留研究面板，点击分析或信息后展开，可收起；分析内容刷新、参数修改及页签切换不改变棋盘几何位置。
- 分支卡片在研究面板显式展开／收起后重新约束位置，保留拖动位置；消除导航行内边距造成的 4px 隐式滚动。
- 拆棋改为测量剩余棋盘区域，覆盖手机、横屏及 iPad。计算内容不参与棋盘尺寸分配。
- 做题页压缩顶部导航、计时、按钮和讲解入口。提示、重来、查看解析在手机上同排；操作按钮 36px、题目导航和结束按钮 34px。功能保留。
- 做题棋子采用与拆棋相同的 94.6% 比例，移动、拖动及吃子残影一致放大。375px 夹具中棋盘由约 286px 扩大至 359px；390px 为 374px。
- 困毙仍使用独立的“困毙”语音与印章。音频改为较低声区、短促收尾与终局冲击音，时长 0.76 秒；没有将绝杀的词语混入困毙。生成方式见 `scripts/generate-stalemate-feedback.py`，不声称与视频原声相同。
