# 1.0.9（10127）残局题库紧凑布局与目录入口

## 变更

- 按用户本轮两张题库截图调整实用残局的题目列表和书本章节页，保留浅绿界面、现有棋盘缩略图、筛选和账号题解权限。
- 压缩题库标题、返回栏、学习方式、路径、筛选和章节行的高度；路径不再重复当前标题。题目卡片保留缩略图，长标题最多两行，来源单行省略，“看题解”移到卡片右下角，保留明确的独立按钮。
- 题号导航默认收为“跳题 / 已显示 X / 共 Y 题”一行，展开后保留数字跳题、分组与悬浮能力。切目录收起；关闭时不挂载旧悬浮导航，避免历史悬浮偏好导致意外遮挡。
- 新增“目录”入口和底部面板：显示真实书本/章节、可练题数及当前目录；可从路径或上级浏览，展开下级，直接选择同级目录，分页读取更多目录。关闭/Escape不改变当前页面；选择仅切目录，不开始做题或发布作业。
- 目录复用原有授权、缓存、请求取消与分页能力，不新增服务端接口或存储。网络错误可重试，账号切换时随既有范围重置。
- 列表底部按钮改称“下一页题目”，沿用原有按页追加并保留已加载题号的行为。
