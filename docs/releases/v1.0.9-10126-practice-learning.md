# 1.0.9（10126）统一做题布局与学习思路

## 实现范围

- 杀法与实用残局共用标题、题号下拉、导航、棋盘、计时和操作区；删除做题页重复的数字导航行。其他页面数字导航保留。
- 手机竖屏按宽度展示棋盘，短屏允许滚动；横屏和平板宽屏将操作区放到棋盘右侧。棋盘缩放只依赖视口，不依赖题解、判题结果、提示或讲解高度。标题省略，状态提示固定高度。
- 新增“学习思路”底部面板，独立滚动。作答前只展示按目标区分的通用观察方法，不从题名推断技术，不提前展示已有题解或私有注释。
- 面板与棋盘提示共用原有三级提示和记录。提示失败不扣次数，重复请求受锁保护；切题、换账号、走子或结束后丢弃过期提示结果。
- 允许查看答案的账号在完成或主动查看解析后，可查看已有 logic 主题、首着思路、关键防守、易错原因及复习要点；缺失时显示明确标注的通用复盘清单。学生/作业答案权限继续生效。
- “讲解这步”打开同一学习面板。关闭卸载讲解，取消旧讲解任务；切题/账号变更重置面板。打开面板直接停止解析播放，末尾不调用可能重播的切换操作。
- 已完成后查看题解不再次提交成绩；“遮住解析，重新做一遍”复用重做，保留错误、提示与用时，不自动标为掌握。
