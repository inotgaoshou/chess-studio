# v1.1.0（10139）平台作业库加载与目录删除

## 修复

- 平台作业库原来并行读取后统一等待；题目旧完整查询超过12秒，连已读到的目录也不显示。改为目录结构、统计、题目独立更新，题目复用 `pageOnly=true&limit=50`，生产同一节点实测608毫秒返回50题。
- 目录结构使用 `view=structure&allowStaleCounts=true`，数量另读 `view=counts`。未知题数显示“题数统计中”；统计失败不隐藏已读取的目录和题目。
- 每次读取10秒上限，超时显示重试；筛选和返回保持可操作。离开、筛选变化与卸载取消旧请求，代次校验防止迟到结果覆盖新页面。
- 我的题库／我的作业库支持删除可编辑的空目录和含题目录。确认框明确保留原题和已布置作业；服务端锁父目录、验证所有权／机构／范围及修订版本，只删除目录引用和目录。
- 未传 `removeItems` 的旧客户端仍仅允许删除空目录。重复请求安全；删除成功立即更新列表，后台刷新独立。旧目录的本机草稿可在剩余可编辑目录继续。
