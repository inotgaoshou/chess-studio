# 1.0.9（10130）杀法与残局学习路线

## 使用与范围

题库首页顶部增加“杀法学习路线”和“残局学习路线”。打开面板查看推荐顺序、每阶段观察方法、练后自查，再主动选择对应题库。阶段可以自由选择，不自动开始做题、打开答案、发布作业或计算掌握度。

- 杀法：一步杀 → 两步杀 → 三四步计算 → 连将与非连将 → 实战与残局杀法。
- 残局：基本胜和 → 兵卒参与 → 车马炮参与 → 按书本章节 → 优势兑现与复盘。
- 实际进入现有题库，复用一步至四步、残局胜法/求和、任一方含兵种和书本视图。选择新阶段清除上一阶段筛选；同一账号返回题库保留阶段提示。该提示是本次浏览上下文，不是服务器学习记录，也不保证重启持久化。
- 题内继续使用已有学习思路、计数提示、题解、朗读与重做；看过题解不自动标为掌握。
- 目录按真实 `teachingEntry` 匹配，使用现有账号授权接口；只启用有效、已确认且有题或题数尚待统计的专题。空目录、权限不足、读取失败明确提示；根目录支持分页与重试，不根据名称猜分类。
- 不改变教师作业选题流程，不增加服务端接口、存储字段或掌握度系统。
