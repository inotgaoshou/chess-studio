# v1.1.0（10137）目录与选题响应优化

## 修改

- 目录保存成功即关闭弹窗，并更新目录；后台刷新独立进行，失败可单独重试。
- 创建目录的超时重试复用 UUID，避免重复；打开目录直接读取详情。
- 题库先展示分页，再独立统计总数；取消过期请求，当前会话缓存展示后仍验证有效性。
- 保留每页 50 题、跨页全选、内容去重、目录 1000 题限制和个人／机构权限隔离。
- 只确认添加题目，不自动发布作业。

## 已完成验证

- 移动端 249 项 UI 测试、67 项逻辑测试通过，TypeScript／Vite 构建通过。
- 服务端常规测试 99 项通过、18 项忽略，独立临时 MySQL 验收通过。
- Chromium／WebKit 共 14 组尺寸验证通过，覆盖 320／390／430px、横屏、iPad 及后台宽屏；慢刷新不阻塞保存，总数延迟不阻塞题库，分页与跨页选择正确。
- 模拟保存响应后解除弹窗耗时：Chromium 22–26ms，WebKit 2–5ms，低于 100ms。
- 后台构建通过；完整后台测试中有 4 项既有失败（3 项打卡测试、1 项固定旧棋谱依赖缺少 @capacitor/core），本轮未修改这些功能。

## 发布边界

服务端使用生产基线隔离分支、固定提交和固定旧版棋谱依赖；不运行数据库迁移。测试环境保持停止，不备份、不卸载、不替换审核构建。真机听音、触控及人工验收不由浏览器自动化代替。
