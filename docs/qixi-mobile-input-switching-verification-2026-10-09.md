# 移动端输入与逐题回放验收（2026-10-09）

## 实现

- APK／IPA 使用 Capacitor Keyboard 原生事件结合 visualViewport；取已缩高视口和键盘扣减结果中的较小值，不重复扣除键盘。
- 输入页随可见区域缩高，底部导航隐藏，作业步骤操作条进入正文滚动；输入字号至少 16px。焦点切换、输入法候选栏变化、长备注输入后重新检查滚动容器。
- iPhone 初始化恢复系统键盘辅助栏的“完成”，不替换多行回车、不提交或切换步骤。作业向导正文与操作区分为独立布局行；键盘打开时变为整页滚动，保持输入组件和草稿不变。
- 极短横屏键盘视口隐藏应用顶栏；保存弹窗整体滚动，避免固定操作区压掉全部正文空间。键盘关闭后恢复正常布局和输入内容。
- 逐题回放保留原棋盘，按需读取下一题，准备局面、中文着法和已解码图片后原子切换；失败可重试，返回或刷新使旧请求失效，成功从第 0 手回放。
- 题号默认收起，记住本设备选择；展开时仅滚动题号网格，使当前题号可见。已有账号、棋谱及导航偏好不做迁移或清空；服务端 API 和数据库不变。
