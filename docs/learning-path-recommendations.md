# 杀法与残局学习路线建议

这是对现有题库的学习顺序建议，不代表已上线个人化推荐或长期掌握度系统。现有题库可以按目录、步数练习，题内提供学习思路、提示、解析回放与重做。

## 杀法路线

1. 基础杀法与一步杀：先找将位、可逃位置和直接将军点，练习准确识图。
2. 两步杀：先算对手最强的应手，再验证自己的第二着；不能只找第一步。
3. 连将杀与三四步杀：按“将军—全部合法应手—继续将军”展开计算，检查是否漏掉防守。
4. 非连将杀：学习封路、控制逃点与准备着，说明为什么暂不将军仍形成威胁。
5. 实战杀法、残局杀法与中局战术：在复杂局面中区分直接取胜、得子和先改善位置的选择。

## 残局路线

1. 基本胜和：先分清题目是求胜还是求和；理解将帅安全、兵的进退和防守资源。
2. 单兵种与基础配合：按实用残局的书本目录学习车、马、炮、兵及其常见配合；优先老师已指定的基础章节。
3. 多兵种综合：关注限制对方子力、改善己方位置、交换是否有利及关键防守。
4. 优势兑现与实战转换：比较不同应手，说明何时应交换、推进兵或转入另一种残局。
5. 求和与顽强防守：练习识别堡垒、防守阵形和避免错误交换；不把引擎分数直接当作必胜证明。

## 每次练习怎么学

- 每次约 15–20 分钟，选同一主题 5–10 题，重质量而非刷数量。
- 先看学习方法，独立尝试；困难时逐级提示；主动看解析后用回放核对对方最强应手。
- 用一句话解释“第一着解决了什么、对手怎样抵抗、自己最容易错在哪里”。
- 遮住答案重做，隔天和一周后复习；看过解析不自动算掌握。
- 连续练习仍不稳定时退回上一阶段。具体进阶由老师与学习者复核，不编造统一通过率或自动掌握结论。
