# 1.0.7 / 10065 移动端修复验收（2026-10-25）

已覆盖安装到 iPad Air 2（iOS 15.8.7），设备回读为 1.0.7 / 10065，未卸载应用。签名版 Android APK 同步生成，包名 cn.xiangqi.endgame.training，ARM64，最低 Android 10。

## 保存与键盘

- 对局日期固定显示 YYYY-MM-DD，时刻为24小时 HH:mm；保留系统日期/时间选择器，显示文本不再受系统英文日期格式影响。
- 打开保存/编辑时不自动弹键盘，横屏采用双列表单；表单可独立滚动，字段标题、时间预览与底部按钮可见。
- 收起、取消和保存会等待键盘与视口恢复稳定后关闭；弹窗打开时暂停底层棋盘尺寸观察，关闭后沿用原棋盘节点。
- 保存元数据后立即更新列表，不等待后台目录刷新；只修改元数据，着法、分支、注释保留。

## 打开习题与走子

- 已保存局面先展示，路线复核在后台进行；复核期间显示提示，不把等待中的路线判为完成。
- 返回题库后迟到的复核结果不能重新打开棋盘；不重复创建练习会话。
- 步数Tab保留各范围第一页显示缓存，后台仍重新请求，不把显示缓存作为取题资格证据。
- 落子先更新棋盘，中文着法转换移到首帧之后；自动保存保持队列和版本保护。
- 吃子提示900ms、将军1500ms；与棋子移动分离，普通移动仍为180ms，不等待提示结束。动画仅使用透明度和变换，不做动态模糊。

## 净得子规则

- 共享规则修复：将杀/困毙但没有实际子力净收益，不能算净得子完成；先考虑对方应手，再按净收益阈值判断。
- 移动端对服务端的净得子“完成”结果再次核对实际线路，避免旧规则误完成。
- 这并不代表5,000题已线上发布。该来源杀棋任务已取消，杀棋自动发布已关闭；按净得子进行的本地逐题审核和后端目标纠正另有记录。
