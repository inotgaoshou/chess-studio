## 已复现与修改

- `chooseStep` 原来删除目标步数的全部显示缓存。已加载的两步杀切走再切回，遇到挂起的重新读取请求时列表会持续空白。`test-catalog-tab-speed-ui.cjs` 修改前在400ms可见性检查失败。
- 现保留每个范围、统计版本、筛选组合对应的第一页和下一页游标。切Tab仍重置分页，立即展示该第一页，后台继续实时请求；切账号/机构/权益仍使用原有隔离缓存和内容重置机制。不缓存完成授权或绕过服务器取题资格。
- 当前本地工作树的练习恢复改动将可选的路线复核移到合法棋盘展示之后；会话、棋盘和本地恢复仍先准备。相关进度、计时与判题规则不变。复核期间明确提示、暂停有效计时；不将等待中的路线标为答对。
- `test-practice-resume-speed-ui.cjs` 修改前在1200ms等待做题页面超时；当前Chromium 390/1024px分别122/118ms，WebKit分别113/86ms显示棋盘（模拟服务器已返回会话、复核请求挂起的情形，非公网总耗时）。
