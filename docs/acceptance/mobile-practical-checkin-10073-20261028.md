# 移动端实用残局与教师打卡 10073

## 修复与新增

教师学习打卡原先直接把后台工作区放入教师 shell，未使用移动端独立滚动容器。在 App 固定视口/禁用页面滚动的布局中，超出屏幕的任务和底部保存按钮不可达。现使用与教师其他页面一致的独立滚动容器，保留键盘缩小视口、底部导航和安全区适配；表单顶部增加保存草稿/保存修改入口，仍使用原有校验和保存流程。日期字段约束为可收缩的单列网格。

实用残局列表增加每组 20 个题号、已加载题号范围切换和定位。分页继续按需加载，不一次下载全库。做题页直接显示本组数字导航，保留跨组切换。列表、做题页根据 libraryId 匹配已加载的书籍元数据，显示书名和原题序；不猜测缺失来源，其他杀法类不显示来源。

实用残局移动端筛选增加车、马、炮、兵卒，含义为任一方含该兵种；请求真实服务端筛选，支持清空、重新编号、返回后恢复筛选。
