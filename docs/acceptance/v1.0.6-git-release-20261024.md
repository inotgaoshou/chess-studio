# v1.0.6 代码归档与打包标签

发布标签以 `api-release-10037` 工作目录中的最新正式客户端源代码为基准，包含 iOS 1.0.6（10054）的 iOS 15 配置及本轮客户端修复。桌面端 npm、Tauri 和 Cargo 工作区版本统一为 1.0.6，Cargo.lock 同步更新。

主目录原先位于 v1.0.5，85个未跟踪文件先保存在历史提交 `8f854a0e`。仅主目录存在的76个历史验收文件纳入本版本；已存在的同名较新实现保留，不用旧文件覆盖。历史提交保留其余旧文件的完整版本。

## 提交前验证
