# 棋谱学习重复条目修复（10045）

## 根因与范围

正式基础杀法目录的列表返回了不同ID、相同完整内容指纹的条目。核对详情后，既有同一来源重复导入，也有两版教材内容相同的记录；另有同名但不同局面的题，不能按标题合并。复现数据保存在 scripts/fixtures/catalog-reading-duplicates.json，不含账号或令牌。

棋谱学习展示按服务端64位十六进制 contentFingerprint 去重，保留首次出现的ID及原顺序；该指纹绑定标题、FEN、完整题解、注释、目标和发布属性。无有效指纹时只按ID合并。分页和缓存继续保存原始ID集合，在展示时合并，因此跨页及缓存恢复均生效。新增48px棋盘缩略图及先行方，让同名不同局面可区分。

不物理删除题目、来源或引用，不更改API、权限、训练/教师选题集合、题数口径、成绩或作业。不同完整指纹的内容保留；这不是全库内容清理，也不承诺将注释、版本不同的题目强行合并。

## 回归证据

原UI回放运行 `node scripts/test-catalog-reading-dedup.cjs`，修复前在真实React界面失败：第一页预期3条、实际4条。修复后6条原始记录分两页显示4条学习入口，保留3个同名不同局面。点击保留首条实际ID，训练原始条目仍可见。

- 普通学生、VIP学生、老师 × 375/390/430/800px，12组UI回放通过：首屏/跨页去重、同名异局保留、缓存恢复、打开ID、缩略图、44px操作区域与无横向溢出。
- 39项前端测试通过（新增3项指纹、顺序、旧数据与不同题解边界）；TypeScript、Vite正式构建通过。
- 教师作业向导390/1024px回归通过：跨章节选择、题序、去重与分批提交载荷。写入由fixture拦截。
- Android原生模拟器独立包 cn.xiangqi.endgame.training.librarystudy 通过首屏/跨页合并、缓存、训练切换和缩略图。
- iOS18.6模拟器同一独立包，XCTest最终运行1场景、0失败；覆盖首屏/跨页、训练切换和恢复。前两次测试定位未识别aria-pressed控件，改为通用可访问性定位后通过，无相应产品代码改动。

截图、日志及最终XCTest源文件保存在本地忽略目录 artifacts/release-1.0.6-10045/evidence。原生模拟器使用正式构建资源及隔离fixture；网络性能、真实学生成绩未在此回放中重测。用于核实线上重复内容的临时运营会话已撤销，并确认旧令牌HTTP401。
