# iPhone 1.0.6（10049）正式环境覆盖安装

日期：2026-10-23。

## 交付结果

- iPhone 14 原版本 1.0.6（10048），以相同应用标识 `cn.xiangqi.endgame.training` 覆盖安装 1.0.6（10049）；安装成功后读取设备应用信息确认构建号。
- 没有卸载，没有新增业务数据备份，没有在真机执行自动点击；最终页面操作由用户验收。使用覆盖安装保留原数据，但本轮未读取业务数据逐项比对。
- 正式 API 固定为 `https://api.qixiapp.cn`，正式客户端禁止环境切换。未修改服务器或数据库，未上传 App Store 或提交审核。

## 本包修改

- 手机题库移除无数据支撑的难度、子力筛选；关键词筛选防抖和清空分页修复。
- 从目录点题时传入同组最多20道题，并定位点选题；多题显示上一题／本组数字选题／下一题，进度使用实际组内数量，平板保留数字导航。真正单题仍隐藏导航。
- 打开练习按主键读取缓存，缓存读取及停止引擎并行，保留超时、取消及重试。
- 手机老师／管理员平台训练库隐藏 `other` 分类入口；独立管理后台网页不在本次安装范围内。
- 既有单题会话保留，不把历史1题会话虚改成多题。验收分组导航请返回题库列表重新点题；列表若被筛选到仅1题，仍属于单题练习。

## 构建隔离与校验

- 以10048已验证Archive为原生基线，仅替换当前生产前端及版本元数据，再导出重新签名。
- 没有编译工作树中未完成的 Rust 改动。去签名后的原生主执行文件机器码与10048完全相同；WASM6个文件、NNUE、皮卡鱼版本资源哈希一致。
- 导出包前端文件与本次生产dist逐文件哈希一致，未含模拟器fixture注入。
- 包版本1.0.6／10049，签名团队及iPhone授权校验通过；codesign深度严格验证通过。完整SHA-256和资源校验见同目录 `verification.json`、`SHA256SUMS`。
