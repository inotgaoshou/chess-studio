## 本轮变更

- 合法错着可以进入试走，皮卡鱼按真实局面应手，之后简短提示；连续试走不修改已接受路线、不保存答对成绩。退回重试恢复最后已接受局面。双方复现仍遵循原谱。
- 移除大块待复核横幅和“全部分类”；目录保留搜索及默认折叠筛选。学生根目录不显示目录搜索。
- 打开题目共享15秒整体期限，覆盖鉴权、正文、原生初始化和本机读取。取消或切页后丢弃迟到结果，初始化重试复用已创建会话。
- 合法草稿恢复的可选答案复核最多等待5秒；复核不可用时恢复棋盘并标记待复核，不自动完成。
- 老师默认个人试做，独立题解查看不创建练习会话；布置作业继续使用独立多选。目录缓存刷新后返回保留层级。
- 题目列表携带 `pageOnly=true`，避免旧请求路径等待超过20秒。新增学生只读详情与老师个人试做接口；实时权益与发布权限继续校验，老师不写学生成绩。
