## 后端性能证据

使用正式数据规模的候选服务进行只读 HTTP 验收；连接执行 `SET SESSION TRANSACTION READ ONLY`，不执行迁移、不启动内容修改任务。客户端缓存不参与计时。每个接口以实际首请求及重复请求测量，状态码、非空内容及耗时一起验收；不将拒绝访问、空列表或超时当作性能通过。

v17 首请求：学生题目首屏从 18,320ms 降为 554ms，第二个章节首屏从 3,095ms 降为 407ms。目录、搜索为 166–621ms。仍失败的请求为首页 1,090ms、题库来源 6,963ms、棋谱来源 6,963ms、杀法合集 26,908ms，因此 v17 未通过 1 秒验收。

后续候选将来源统计移为持久化展示投影，后台保留同一审核和证据校验。首请求读取派生统计并合并当前账号进度，实际取题、练习及提交仍实时校验。统计文件按数据库、内容 epoch 和审核规则隔离，原子替换且不按版本累积；无兼容数据时明确返回统计准备中，不填假零。正式规模的最终计时将补录后端验收文档。
