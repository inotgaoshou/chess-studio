## 本轮变化

| 方面 | 用户可见变化 |
| --- | --- |
| 着法教学 | 已走着法提供“讲解这步”，历史着法提供“讲解”，候选提供“为什么推荐”；有题解权限的训练场景支持说明 AI 应手。 |
| 讲解内容 | 按局面问题、这步作用、对手应对、后续计划、注意事项组织；压缩重复说明和子力清单，只陈述事实与参考变化支持的结论。 |
| 中文棋谱 | 讲解、候选及题解变招使用中文着法；未能转换时提示待核对，避免直接展示 ICCS 编码。 |
| 参考变化 | 改为“后续变化（双方共 N 步）”，注明包含当前这步、每次落子计一步，并逐步标记行棋方；最多 12 次落子。 |
| 语音 | iOS/Android 系统中文朗读，手动播放、停止、调整语速；缺少离线声音保留文字并提示安装，不申请麦克风权限。 |
| 状态与权限 | 切题、切步、换分支、权限变化和进入后台时停止旧讲解或语音；受限题目遵循现有答案权限。 |
| 引擎协作 | AI 应手和训练验证优先于普通分析及讲解；实战非首选着法按实际走后局面解释。 |
| 打开习题 | 列表点击立即反馈；历史记录随后加载，避免拖住棋盘；旧历史结果不能覆盖新题目。 |
| 底栏布局 | 提示文字与讲解按钮分开，整行至少 44px，长文字省略；按钮与工具栏不再重叠，保留安全区。 |

安装包还包含当前工作区已有的棋谱目录收起/展开调整，以及吃子专题取消强制得子目标筛选，保留同专题中已审核的杀棋题。这些一并计入本次包的变更范围。

讲解为本地棋规事实和引擎线路的说明，未接入大模型；不声称读取 Pikafish 内部思考，不修改棋谱树、注释或评分。

## 已完成验证

- Rust 核心与 WASM 适配测试：35 项通过。
- 移动端逻辑测试：61 项通过；UI 测试：84 项通过。
- 真实 App/WASM 浏览器回归：390×844、375×812、844×390、1024×768；涵盖历史红黑着法、切步清理、单一讲解面板、面板滚动、底栏展开/收起、长提示省略、安全区以及按钮中心/四角命中。
- 模拟接口测试：历史读取额外延迟 1.2 秒时，点击反馈约 45ms、会话接口返回至棋盘出现约 62ms。仅说明客户端不再等待历史；不代表生产接口或真机端到端耗时。
- WASM、前端生产构建、Android Release 构建和签名校验通过；引擎及 NNUE 哈希、许可证由构建脚本校验。
- 从 APK 内确认中文变化文案、修复后的底栏样式、语音插件、WASM 事实接口及 ARM64 Pikafish 已实际打包；无麦克风或录音权限。
- iOS 开发签名构建成功，最新预览版安装并启动于 iPhone 14。
