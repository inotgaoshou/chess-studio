# v1.0.5 Android 正式 APK 验收（2026-10-15）

交付 `artifacts/v1.0.5-production-10029/qixi-v1.0.5-10029-production.apk`，版本 1.0.5 / 10029，包名 `cn.xiangqi.endgame.training`，默认连接 `https://api.qixiapp.cn`。最低 Android 10，仅 arm64-v8a。

## 本轮修复

安装验收发现手机壳锁定根容器高度并禁止滚动，而学生打卡页缺少独立滚动区域，导致屏幕下方任务无法触达。为移动学生打卡页增加固定于应用标题栏下方的滚动容器；未改动共用打卡组件、后台接口、计划及打卡规则。

新增 `scripts/test-mobile-checkin-ui.cjs`：修复前在 360px 宽度复现“任务无法滚动到达”，修复后在 360×740、390×844、844×390、1024×768 四个尺寸验证按钮可达、提交盖章、当天达标、短周徽章与刷新不重复庆祝。

- 使用 `scripts/build-endgame-training-apk.sh`，显式设置 `VITE_APP_ENV=production`、`ANDROID_VERSION_NAME=1.0.5`、`ANDROID_VERSION_CODE=10029`。
- TypeScript、Vite、WASM、Capacitor 同步及 Gradle Release 构建成功。
- APK 签名验证通过，证书 SHA-256 为 `55e945c2d2e907a450e5c94dbde36b3e99b93551b2a7bf33c0f5bc89f904fe57`，与旧版 1.0.4 一致。

- 源码基于 `f850782fc3189495140b1b478268df89cc13423a`，包含本轮未提交的移动打卡滚动修复；具体源文件摘要、APK 摘要及大小见旁置 `BUILD-INFO.json` 与 `SHA256SUMS`。

## 验收结果

- 18 项移动单元测试、32 项环境及会话回归通过，新增四尺寸 UI 回归通过。
- Android 15 arm64 模拟器覆盖安装并启动正式 APK；原有签名兼容，无需卸载。正式账号登录及线上计划读取通过，最终包检查弘平独立计划、每日两项任务及可触达的打卡按钮。
- 同一源码、同一签名构建的测试环境 APK，在现有专用验收学生账号下通过原生界面完成阅读任务，服务端确认一条提交及一枚印章。
- 数学任务断网确认后显示“本机已记录，待同步”；强制结束并离线重启后记录仍可见，服务端仍仅一条提交。
- 联网刷新后服务端为两条提交、一枚有效“阶段周完成（1天）”徽章，小马显示本周完成 1/1 天；选做任务未提交，不影响达标。再次刷新未重复提交、发奖或庆祝。
- 正式家庭计划、接收名单、任务、提交、审核与徽章在验收前后摘要一致：诗涵 224 项任务、弘平 56 项任务，均无本轮代提交或奖励。验收账号与记录仅存在测试环境。
