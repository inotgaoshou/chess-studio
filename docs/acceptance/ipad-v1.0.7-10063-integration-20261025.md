## 同次提交的移动端功能

- 独立“我的棋谱”：目录、搜索、收藏、移动与删除；编辑指定棋谱信息时保留着法、分支、注释。
- 新建棋谱直接进入录谱，返回恢复原目录和搜索；新建目录不显示底层棋盘。
- 录谱常用工具、导入完整棋谱树、本地背谱练习；分支删除按可达路径清理，排序写入自动保存。
- 修复落子动画坐标及首帧闪动；横屏工具和展开菜单限定右侧，竖屏保留底部布局。
- 杀法快捷入口、题目只读请求的有限重试与超时提示。
- 分享入口移除；视频识谱留待后续。
- Xcode 与 iOS 构建脚本默认版本统一为 1.0.7 / 10063。
