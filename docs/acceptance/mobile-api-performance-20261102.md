# v1.1.0 提审前接口功能与性能检查（2026-11-02）

## 基线

生产专用验收账号，串行低负载请求；不向真实学生发布作业。首轮 87 次请求发现：错题列表及一条平台棋谱详情超过 12 秒；独立二次复测均重现。其他来源选题约 60–90ms，首次搜索约 1173ms。原脚本误用了不存在的 `/admin/students`，已改为真实班级可选学生接口，不作为产品缺陷。

线上只有 `personal_manual_records`，没有云镜像导入与单独同步统计表。普通个人棋谱 POST 同步成功；可选统计、镜像接口未部署。10142 依据服务端 capability 跳过未提供的接口，保留本地统计及普通同步；不宣称云镜像已上线。
