- 新增 `public/audio/checkmate-crisp.wav`，从现有绝杀语音处理得到，保留原文件。

音频生成参数（ffmpeg）：

```sh
ffmpeg -i checkmate.wav -af 'highpass=f=140,equalizer=f=2600:t=q:w=0.9:g=3,acompressor=threshold=0.12:ratio=3:attack=2:release=60:makeup=2.6,alimiter=limit=0.891:level=0' -ar 48000 -c:a pcm_s16le checkmate-crisp.wav
```
