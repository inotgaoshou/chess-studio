# 筛选、做题分组导航与平台来源分类调整

日期：2026-10-23。工作树：`codex/catalog-reading-dedup`。版本保持1.0.6。

## 修改范围

- 手机题库浏览移除难度、局面子力筛选，并清理恢复位置中的隐藏条件。正式库只读检查：24,157道有效已发布题的difficulty均为空；因此不提供没有数据支撑的难度选项。
- 保留题目目标、精确步数／步数分组；原“杀法名称”改为“题名关键词”，与接口按题名／原分类匹配的语义一致。教师布置作业选题保留原表单。
- 切目录时立即建立新的防抖作用域，关键词编辑等待300ms再查询；清空／改筛选重置题目分页，续页使用与首屏相同的已稳定关键词。
- 从手机目录点某道题时传入所在分组和所选题目；每组最多20道，符合现有练习会话限制。分组ID保留目录顺序并去重，实际会话内顺序沿用服务端返回；不把本组序号冒充整个专题的完成数量。
- 学生初始化明确选择点选题目，即使服务端返回顺序不同也不会打开第一题；选题不再被固定为单题会话。老师试做使用相同分组导航，不创建学生会话或成绩。本地题库增加切题入口。
- 多题展示“本组进度”和上一题／数字选题／下一题；修正平板样式隐藏中间数字按钮的问题。真正的单题仍隐藏整组底部导航。切题前保留当前本地进度和有效用时。
- 打开练习时按IndexedDB主键读取指定会话，不再复制全部历史会话中的完整题目快照；缓存合并读取及停止旧引擎并行进行。新棋盘只在初始化全部成功后提交；沿用15秒总期限、显式重试、连续点击合并和会话复用。
- 手机老师／管理员“题库 → 平台训练题库”分类隐藏`other`，包括该分类显示2本来源的情况；旧来源浏览也不再展示该分类。只调整入口，不删除来源、题目或作业引用。独立管理后台网页未改动、未发布。
