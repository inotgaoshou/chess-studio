# 棋析 1.1.1 视频学习验收

日期：2026-11-02 至 2026-11-03。范围为 `apps/endgame-training` 安卓/iOS 视频学习库与家庭开发安装。保留工作树已有皮肤/设置优化，不改桌面 Tauri 工作台。

## 交付能力

- 首页视频学习/继续学习、“我的”视频管理；没有新增底部导航。
- 本地 MP4 多选与文件夹递归导入、分类/系列/章节管理、自然排序、内容去重。
- HTML5 播放、进度条定位、倍速、全屏、25 段数字分组、书签、手动看过、暂停续播与练棋往返。独立前后 10 秒按钮已按晚间最新要求移除，书签等辅助操作收进“更多”。
- 视频/章节/系列删除，二次确认；保留原始文件和其他引用相同内容的课程。删除部分内容不丢失同系列其他失败项重试入口。
- 独立本机 SQLite 与媒体目录，原生流式复制/校验、导入取消/恢复、排队任务取消；不上传课程。
- `.family` 独立应用标识，安卓/iOS 开发构建、Mac 交互安装及电脑预置脚本。普通包与常规家庭小包不内置私人 MP4；另提供仅在仓库外生成的安卓家庭私人离线包。
