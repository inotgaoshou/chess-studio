# 打开题目超时与按钮样式修复（2026-10-20）

本记录接续 `entry-trial-release-20261020.md`，以下状态优先。用户最新要求先在模拟器验证，最后才由用户做真机验收。本轮已停止 pymobiledevice3 真机测试会话；此后未启动、点击、安装或更改用户手机。

## 原因与修复

10040 真机连续复现：基础杀法 → 1～4步杀专项 → 一步杀 → 0001-1步杀，停在“读取题目”，15秒超时，重试仍失败。Nginx记录POST会话请求499。绕过手机与公网，同一正式审核学生、同一道题在服务器loopback创建会话为37024.66、18807.78、16670.86ms；MySQL活动语句确认虽然外层限定一个ID，内部仍物化全库机器审核与题解哈希。

后端 `8a535f7` 把候选元数据和最终资格核验分开：按顺序筛选后，每批至多20道候选复用目录详情的限定ID审核函数，在同一RR事务里验证发布、来源版本、证明指纹、目标、VIP与机构权限，再获取题解。缺证据的候选不进入会话，并继续补足有效候选。提交、快照和成绩规则不变。

客户端 `bc738e23` 显式设置按钮appearance、背景、字体、边框与6px圆角，重试为绿色主操作，取消为白底描边；最小高度44px。当前iPhone仍是原10040，样式需后续客户端包覆盖安装才能生效；没有把源码修复描述成已安装。
