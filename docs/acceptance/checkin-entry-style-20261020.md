# 学生打卡入口与页面样式验收

日期：2026-10-20。使用本地 Vite 与合成学生数据，不访问或修改线上打卡数据。

## 调整

- 首页打卡卡片加入绿色日历打勾图标，整张卡片可点击；手机、平板均占整行，8px 圆角与相邻卡片一致。
- 学生打卡页采用居中标题和两侧返回、刷新图标，点击区域为 44×44px，保留按钮的无障碍名称及加载禁用状态。
- 无计划时显示带日历图标的提示卡片；旧详情清理后再显示空状态，避免短暂同时出现旧任务。
- 共享打卡组件与样式同步至 admin-web。

## 验证

- 移动端单元测试：28 项通过。
- 共享 UI 回归：22 项通过。

- `scripts/test-mobile-checkin-ui.cjs`：360×740、390×844、844×390、1024×768；提交按钮可触达、打卡盖章、徽章及刷新不重复庆祝均通过。短列表无需产生滚动，测试检查滚动容器与展开后按钮的实际可触达性。
