# 残局训练专题设计稿（Android / 桌面）

> 设计问题：如何让用户在不同屏幕上以最少干扰完成一道残局，而不是停留在题库浏览或设置操作中。

## 产品定位

“棋研”是一个离线优先的残局训练专题。它不是棋谱编辑器，也不应做成首页加卡片的内容门户。每一次打开应用，用户应在 2 步内到达棋盘并开始走子。

训练闭环：选题 -> 解题 -> 获得即时反馈 -> 复盘答案 -> 进入下一题。

共享原则：

- 棋盘永远是视觉重心；训练动作在棋盘附近，不让用户在侧栏里找主要按钮。
- 目录、模式、历史均是辅助信息。它们在安卓上按需出现，在桌面上可并列出现。
- “提示”是唯一主命令；暂停、重来、看答案都是次级命令。
- 只用本地题库和记录做事实来源。云库或 AI 是应手增强，失效时必须自然退化为离线双人。

## 桌面：沉浸式工作台

适用宽度：`>= 840px`。默认三栏，但中间棋盘区始终优先获得空间。

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ 棋研 / 当前题库                                      导入题库  帮助      │
├───────────────┬──────────────────────────────────────┬───────────────────┤
│ 题库与筛选    │  第 12 / 80 题  |  车兵残局：巧胜     │  本题用时  02:14  │
│ ───────────   │                                      │  累计 18:32       │
│ [搜索] [类别] │              [  棋盘  ]                │ ───────────────── │
│ ○ 12 车兵残局 │                                      │ 对练模式          │
│   未练        │          当前任务 / 即时反馈          │ ● 云库  ○ 解题   │
│ ○ 13 马兵残局 │                                      │                                      │
│               │                                      │ [ 提示 1/3 ]      │
│               │                                  < > │ [暂停] [重来]     │
│               │                                      │ 错误 0 次         │
└───────────────┴──────────────────────────────────────┴───────────────────┘
```

- 左栏宽 `250px`：只保留题库、筛选和题目列表。题目行显示序号、标题、类别和练习状态，当前题用细边框与浅蓝底定位。
- 中栏最小宽 `460px`：标题只出现一次，棋盘宽度受高度限制，防止超大显示器使棋盘失真。下方仅放一句可执行的当前提示和前后题箭头。
- 右栏宽 `238px`：以时间、模式、训练命令、即时反馈为顺序。记录和答案在此栏内替换显示，避免弹窗打断走子。
- 宽度 `840–1120px` 时，左栏可折叠为图标栏，确保棋盘不低于可用高度的 72%。

## Android：一手可达的训练台

适用宽度：`< 840px` 或竖屏。默认不同时展示目录和控制区，用户进入后直接看到题目和棋盘。

```text
┌────────────────────────────┐
│ 题库       棋研       控制 │  56px 固定顶栏
├────────────────────────────┤
│ 第 12/80  车兵残局：巧胜    │
│                            │
│        [  棋盘  ]          │  棋盘占可视高度的主要部分
│                            │
│ 云库自动应手 · 错误 0 次   │
├────────────────────────────┤
│ [提示 1/3] [重来] [暂停]   │  48px 触控命令带
└────────────────────────────┘
```

- 顶栏只有“题库”“控制”两个图标入口，配合无歧义的 `aria-label`。导入与帮助归入对应抽屉，避免顶栏出现四个等权按钮。
- 棋盘最大宽度为 `92vw`，同时受 `100dvh` 约束，不能挤压命令带。棋子点击热区不小于视觉棋子，目标点在手指操作时保持可点。
- 底部命令带固定在棋盘之后，不使用悬浮卡。提示为主按钮；其余命令为等宽次按钮；“看答案”替换暂停位，不新增一行。
- 左抽屉承载题库、搜索和筛选；右抽屉承载模式、记录、答案与屏幕方向。抽屉打开时有遮罩，点击遮罩返回棋盘。
- 横屏安卓可回到桌面式三栏，但左右栏默认收起为窄抽屉按钮，避免系统状态栏和虚拟导航栏吞掉棋盘高度。

## 关键状态

| 状态 | 棋盘附近信息 | 主命令 | 不应发生的事 |
| --- | --- | --- | --- |
| 未选题 | 导入或选择残局 | 选择题目 | 显示空的计时、模式面板 |
| 正在作答 | 当前模式、错误次数 | 提示 | 为每个操作弹出确认框 |
| 自动应手 | “对方正在应手” | 停止等待 | 允许用户继续落子 |
| 解出 | 完成反馈、用时、提示数 | 下一题 | 自动跳下一题，导致错过反馈 |
| 看答案 | 回合列表和演示进度 | 演示答案 | 将演示走子写入训练记录 |
| 离线退化 | “转为离线双人” | 继续训练 | 把网络失败渲染为阻塞错误页 |

## 视觉语言

- 基调：纸白、淡竹绿、朱砂红和棋盘木色。用于专注训练，不借用桌面专业模式的深色工作台。
- 信息面优先用分隔线和留白，不把页面切成层层卡片；圆角不超过 `6px`。
- 红色只表示棋子、错误或危险操作；绿色只表示可继续训练与完成状态；提示使用琥珀色。
- 文字层级限定为：专题名、题目名、关键计时、辅助说明四级。时间使用等宽数字。
- 动效只用于将军、吃子、完成等棋局事件；支持 `prefers-reduced-motion`，不能用动效作为信息唯一载体。

## 验收要点

- Android 360 x 800 与 412 x 915 竖屏：不横向滚动；棋盘、题名、命令带不重叠；抽屉以外不残留可点击控件。
- 桌面 1280 x 800：棋盘完整可见，目录、控制和答案可扫描；不需要滚动页面才能提示或进入下一题。
- 无云库、无 AI 或断网时，开始、落子、重来、看答案和保存记录仍可完成。
- 所有“预览答案”只改变临时棋盘状态，不能写入题库、答题记录或真实题解树。
