构建：1.1.0（10143），生产环境。浅绿统一配色，截图上方为中文功能说明。

顺序为大棋盘练习、学习路线、AI分析、分组分页。PNG为RGB，无透明通道。

## 使用路径

1. 登录后进入“题库”，选择杀法或残局；筛选后可直接查看题目。每页50题，每组25题，末组按实际剩余题数；数字导航可切组、分页及查看完成标识。
2. “题库 → 杀法学习路线／残局学习路线”，选择阶段阅读学习方法，再进入练习；练后可用自查要点复盘。
3. 做题时先观察棋盘，按需使用三级提示；“查看解析”支持单步回放、播放，中文讲解可主动朗读。
4. “我的 → 我的棋谱”或“拆棋分析”，打开棋谱并点击分析；AI按禁用→局势→提示→局势→禁用循环。候选使用中文着法，小棋盘用于临时推演，保存前不修改原棋谱。
5. iPad竖屏上下排布，横屏将内容置于棋盘侧边。页面、棋盘、棋子均为对应设备适配后的实际界面。
