# 审核操作说明草稿

正式包连接生产服务。基础本地功能仍可免登录使用；师生、作业和平台练习需登录。独立审核账号无短期到期限制，密码通过 App Store Connect 审核信息字段单独提供。

教师账号：`review.teacher.103`。学生账号：`review.student.103`。

学生账号由老师在“班级与学生 → 创建并加入学生”中创建并设置初始密码；学生使用老师提供的账号登录，不需要自行注册。审核学生已开通永久 VIP。

1. 登录教师账号，进入教师工作台，选择“1.0.3 审核班”。已有 3 题审核体验作业，也可从公开题库选择题目并指定审核学生发布作业。
2. 退出教师账号，登录学生账号，打开作业列表，进入“棋析 1.0.3 审核体验作业（3题）”。
3. 完成三题后返回作业，检查答案并手动确认提交。可使用答案查看功能体验题目；完整完成统计应通过正确解题获得。
4. 退出学生账号，再登录教师账号，打开该作业结果。汇总区区分部分提交、全部提交和全部做对；点击学生查看逐题分数、星级、错误与提示次数，再点击题目查看初始棋盘、中文着法和只读回放。返回按钮逐级回到逐题列表、学生列表和教师工作台。
5. 学生首页可体验“基础杀法”专题、10 题日练、收藏和搜索。

原有师生真机视频已有密码遮挡、静音副本。需补录最终版本的学生“检查 → 确认提交 → 成功”和教师“汇总 → 学生成绩 → 题目回放 → 返回”。最终截图与补录尚待采集，不将浏览器回归截图用作商店原生截图。

## 隐私核对

提交前核对实际数据流并更新 App Store Connect：账号标识和登录信息、班级与机构关系、作业和练习记录，以及主动同步的个人棋谱、目录、注释和分析摘要均会发送到生产服务。会话凭据由原生安全存储保存。可选 ChessDB 云库查询发送当前 FEN。不要直接沿用 1.0.2“无需账号或服务器 API”的审核描述。

隐私政策、账号删除入口和商店隐私声明需在最终包中逐项确认。

账号删除入口：“我的 → 账号与机构 → 申请删除账号”。输入当前密码并确认后申请由平台管理员在 7 日内人工处理，完成前可取消。申请受理不是已完成删除；审核账号请勿用于删除验收。
