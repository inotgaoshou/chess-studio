# 审核操作说明草稿

正式包连接生产服务。基础本地功能仍可免登录使用；师生、作业和平台练习需登录。独立审核账号无短期到期限制，密码通过 App Store Connect 审核信息字段单独提供。

教师账号：`review.teacher.103`。学生账号：`review.student.103`。

1. 登录教师账号，进入教师工作台，选择“1.0.3 审核班”。已有 3 题审核体验作业，也可从公开题库选择题目并指定审核学生发布作业。
2. 退出教师账号，登录学生账号，打开作业列表，进入“棋析 1.0.3 审核体验作业（3题）”。
3. 完成三题后返回作业，检查答案并手动确认提交。可使用答案查看功能体验题目；完整完成统计应通过正确解题获得。
4. 退出学生账号，再登录教师账号，打开该作业结果查看学生记录。
5. 学生首页可体验“基础杀法”专题、10 题日练、收藏和搜索。

录屏及新截图尚待真机采集。不要使用旧版视频或测试环境截图代替此次生产验收。
