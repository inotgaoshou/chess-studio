# 真机录屏脚本（目标 3–5 分钟）

使用连接生产服务的最终 iOS 标签构建。开启勿扰，遮挡密码输入及个人通知，画面仅使用独立审核师生信息。输出视频中应可辨识版本、操作和结果。

1. 0:00–0:20：显示版本和正式环境，教师已登录状态。
2. 0:20–1:20：教师选择公开题库的三道题，指定审核学生并发布新的录屏作业。
3. 1:20–1:45：隐藏密码输入画面，切换学生账号并刷新作业列表。
4. 1:45–3:30：学生进入作业并完成三题，返回检查答案并手动确认交卷。其中一题断网完成，确认交卷后显示待补交；恢复联网后显示补交成功。
5. 3:30–4:30：切换教师账号，显示该作业结果和三题完成记录。
6. 4:30–5:00：学生专题与日练入口、收藏或搜索。

录屏完成后检查无密码、通知和真实学员个人信息；核对播放时长、音画可读性。另存关键截图：教师发布、学生作业列表、解题、补交结果、教师结果。

幂等与机构隔离验收可附独立记录，不必挤入视频。接口验收已通过，但不能替代原生缓存和真机操作验收。
